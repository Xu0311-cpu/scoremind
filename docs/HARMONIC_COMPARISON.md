# MVP 3.12 独立和声标注人工对照规则

本视图只帮助校审者在主动揭示机器结果后核对原谱。它不是自动评分、纠错、事件对齐或漏报检测；独立和声包、机器 API 和旧 ExpertReview 意见仍是三份不同的数据。

## 展示门槛

1. 盲态完全不挂载对照组件。只有同一上传文件完成机器揭示和分析后才可进入。
2. 必须有原始文件 SHA-256，并与当前独立标注包一致；书面小节总数、选中书面索引、原谱核验结构、机器时间轴的小节网格及机器 `measure_index` 都要一一对应。每个书面小节的原谱时值必须与时间轴起止和从零累计的边界精确相等（约分分数比较，不用浮点）。显示小节编号不是身份键。无法证明身份时不并列机器与人工判断，只显示不可定位原因。
3. 可证明同谱同书面小节后，人工判断、机器同起点和弦及记谱时间轴证据分栏呈现。时间轴持续音不是新和弦。未标注小节明确显示“尚无人工判断”，不推断正确。
4. **可直接对应**仅限：时间轴 `complete`、双方为记谱音基准、人工条目为单一已确定事件且位置 `0`、机器该小节恰有一个同起点和弦且 `beat=1`，并且根音、质量等必要字段存在。这个状态也只表示位置可供人工核对，不自动比较字段是否相等，更不判对错。人工 `partial`/`unclear`、多事件或多机器和弦、不同音高基准、缺字段、旧响应或时间轴 `partial/unsupported` 均显示“不可直接比较”及具体原因；可核实身份时仍允许分别阅读原始字段。
5. “前往人工意见”只把现有 ExpertReview 定位到当前书面小节，不创建或保存意见。保存必须由校审者在旧表单中明确执行。对照内容不进入学习报告、解释请求或分析 API。

## 验收样例

| 场景 | 预期 |
| --- | --- |
| `simple_chords.musicxml` 上传后未点 Analyze | DOM 与辅助技术均没有机器和弦或对照视图；原谱与独立标注仍可用 |
| 同一文件揭示后，书面第 1 小节，人工单事件 `offset_qn=0` | 可按书面索引并列阅读；满足门槛时只标“位置可供人工核对”，不出现对错/准确率 |
| `timeline_meter_tuplets.musicxml` 两个显示号均为 `1` 的小节 | 书面索引 2、3 分开选择，互不串用机器或人工记录 |
| 更换文件或 SHA 不一致；机器小节结构无法核实 | 不并列数据，旧谱人工记录不出现；不给显示编号猜测位置 |
| 原谱小节时值 `4`，机器时间轴对应 `[0,1)`；或后续小节累计起点偏移 | 不可定位，不并列；即使各 part 的网格彼此一致也不能通过 |
| 刷新并重传同字节文件 | 持久揭示标志恢复后仍须重新取得同文件分析；取得前不挂载对照数据 |
| 人工 `unclear`、无条目、多事件，或机器多和弦 | 分别说明不可直接比较/未标注；不以缺事件推断漏报 |
| 人工 `concert`、时间轴 `partial/unsupported`、缺少根音或机器质量 | 不可直接比较，注明原因；不做移调换算或猜测事件对应 |
| 当前小节点击“前往人工意见” | 现有 ExpertReview 预选同一书面索引，未自动新增意见 |
| 390px 窄屏 | 分栏堆叠、长依据换行，无页面横向溢出；按钮可触控 |

存储/指纹故障沿用 MVP 3.11 的明确退出盲态规则；指纹不可用时禁止对照，但普通 Analyze 仍可继续。本轮不修改后端乐理、上传格式或独立标注 v1 JSON。
